# Ashark-ai-05 Tap

## How do I install these formulae?

`brew install ashark-ai-05/tap/<formula>`

Or `brew tap ashark-ai-05/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ashark-ai-05/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
